# python-active-learning-notebooklm
Neste desafio da DIO, criei um ecossistema de aprendizagem ativa de Python usando o NotebookLM como Professor Socrático. Integrei 5 obras de ponta, documentando técnicas de Engenharia de Prompts, troubleshooting ("cicatrizes") e um miniguia estruturado em 4 fases com glossário e templates de prompts para estudos futuros.
